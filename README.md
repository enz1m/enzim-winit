# enzim-winit

An independently maintained enzUI fork of [winit](https://github.com/iced-rs/winit).

Wayland parent identity, activation, frame pacing, popups, input, session placement and frame shadows.

The canonical repository is [enz1m/enzim-winit](https://github.com/enz1m/enzim-winit).
Upstream crate names, history and license notices are retained.

```sh
git clone --branch enzim https://github.com/enz1m/enzim-winit.git
cd enzim-winit
```

See [FORK.md](FORK.md) for the base and patch list,
[VALIDATION.md](VALIDATION.md) for checks. The
[upstream README](README.upstream.md) is retained.
